# GitHub Workflow Lab

A small sandbox for practicing GitHub issues, branches, pull requests, and merges.

## Practice workflow

1. Open an issue with a concrete task and completion criteria.
2. Create a branch from `main`.
3. Make a focused change and inspect the diff.
4. Open a pull request describing the change and how it was checked.
5. Merge the pull request after the checks appropriate to the change.
6. Close the issue when its completion criteria are met.

This repository contains documentation exercises only. The initial exercise verifies the repository setup and adds this workflow guide through a pull request.

## Achievement experiment

The setup issue was closed within five minutes to try Quickdraw. This guide is merged without a code review to try YOLO. GitHub controls whether and when achievements appear on the profile.
